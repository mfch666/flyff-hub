起航节点防御 · WS 转发模式说明

2026-10-16起航节点防御起航节点防御

面向 开服与服务器防护 —— 通过节点层转发玩家连接，隐藏真实 IP、抵御 DDoS、保障玩家稳定在线。

一、核心特性

  • 🛡️ 隐藏真实 IP：玩家客户端连接的是系统分配的节点 IP，而非你的服务器 IP。攻击者无法直接打到服务器，DDoS 流量被挡在节点层之外。
  • 🔄 节点自动切换：当某个节点被攻击或中断，系统自动将该应用流量切到其它可用节点，玩家几乎无感知，连接不中断。
  • 📶 抗运营商重拨：宽带 24/48 小时强制重拨会让传统直连瞬间断线；本系统通过节点层自动切换，运营商换 IP 也不影响玩家在线。
  • 🖥️ 机器信任管理：可按机器维度标记信任档位（考察 / 信任 / 永久信任 / 直连 unpack），并可备注机器码归属哪个玩家，精细化管理访问来源。

二、几个关键概念

  • 应用（App）：代表一个游戏服务端。每个应用有唯一的 snkey（29 位，相当于账号）与 api_key（16 位，启动凭证），需分别配置到服务端（unpack）与客户端（proxy）才能走代理。
  • 端口映射：每个应用可配置多条「监听端口 → 目标 IP:端口」映射，数量无限制；同一应用内监听端口不可重复。
  • 机器信任：后台「当前访问记录」中，逐台机器设置信任档位，并备注归属玩家，便于排查异常访问。
  • 连接趋势：后台可查看应用的连接数 / 客户端数趋势（24 小时 / 昨天 / 本周 / 本月 / 上月），随时掌握在线情况。

三、组件部署

本系统为节点防御服务，需部署两个组件：

  1. proxy（客户端组件） —— 放玩家机器，与游戏客户端同目录，用后台的 16 位 api_key 以参数方式启动（不可直接双击）。
  2. unpack（服务端组件） —— 放游戏服务器，用 29 位 SNKey 启动（不可直接双击）。游戏服务器只需开放 8889 端口（游戏自身端口无需开放）。

提示：组件下载：登录用户中心 →「端口配置」页顶部有 proxy / unpack 工具包下载链接。

四、整条链路

  1. 把游戏服务端的对外 IP 修改成后台分配给你的节点 IP（例如 127.0.12.34）。
  2. 在用户中心「端口配置」填入你的游戏端口（监听端口 → 目标 IP:端口）。
  3. 玩家机器上的 proxy 与服务器上的 unpack 启动后，整条链路闭环，玩家通过节点 IP 接入。

五、套餐档位

节点防御按套餐档位提供不同连接数 / 客户端数上限与有效期：基础版 / 标准版 / 专业版 / 旗舰版 / 自建版。

  • 档位决定该应用的最大连接数与最大客户端数；额度用尽后新连接按档位策略受限。
  • 到期后仅失去对应额度特权，应用与端口映射保留，不会回收。

六、常见问题

  • 后台显示节点「非活跃」？ 系统会定期检测组件在线状态。若 proxy / unpack 未启动或网络不通即被标记，请检查组件是否运行、端口是否可访问。
  • 组件在哪里下载？ 用户中心 →「端口配置」页顶部「下载附件（proxy / unpack 工具包）」。
  • 套餐到期会回收应用吗？ 不会。仅失去对应额度特权，节点配置保持不变。
  • 能多个游戏服务端共用吗？ 每个应用独立一套 snkey / 端口映射；不同游戏服务端建议分别创建应用。
